OutOfMemoryError; oom-killer; memory_usage

## Diagnostics and uncertainty
Inspect memory limits, allocation trends and OOM logs. Heap capture can pause workloads and expose secrets; seek operator approval.
Correlate event timing and deployment changes. Do not execute remediation automatically.
